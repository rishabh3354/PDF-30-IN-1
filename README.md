# PDF 30-in-1 — every PDF tool in one offline desktop app

**PDF 30-in-1 is a desktop PDF toolkit for Linux and Windows.** Merge, split, compress, convert, edit, sign and
protect PDFs in a few clicks. Your files are processed on your own computer and never uploaded.

  <a href="https://github.com/rishabh3354/PDF-30-IN-1/releases/latest"><img src="https://raw.githubusercontent.com/srevinsaju/get-appimage/master/static/badges/get-appimage-branding-blue.png" height="56" alt="Download the PDF 30-in-1 AppImage"></a>

```bash
sudo snap install pdf-30-in-1
```

```bash
flatpak install flathub com.warlordsoftwares.pdf-30-in-1
```

**AppImage (any Linux distribution):** download `PDF-30-in-1-x86_64.AppImage` from the
[latest release](https://github.com/rishabh3354/PDF-30-IN-1/releases/latest), then
`chmod +x PDF-30-in-1-x86_64.AppImage` and run it.

**Windows 10 and 11:** download `PDF-30-in-1.exe` from the
[latest release](https://github.com/rishabh3354/PDF-30-IN-1/releases/latest), or get it from the Microsoft Store.

## Tools

| Organize | Optimize | Convert | Edit and secure |
| --- | --- | --- | --- |
| Merge PDF | Compress PDF | PDF to Word, Excel, PowerPoint | Edit PDF |
| Split PDF | Repair PDF | PDF to JPG, Markdown, PDF/A | PDF forms |
| Remove / extract pages | OCR PDF | Word, Excel, PowerPoint to PDF | Sign PDF |
| Organize PDF | | JPG and HTML to PDF | Page numbers, watermark, crop |
| Scan to PDF | | | Protect, unlock, redact, compare |

Available in 19 languages, with light and dark themes and touchscreen support.
